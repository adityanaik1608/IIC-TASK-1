# InnovateX 2026 - Premium Event Platform

## Project Description
InnovateX 2026 is a modern, futuristic, and highly interactive landing page designed for a premier tech innovation summit. It provides an immersive user experience with premium aesthetics, guiding attendees through event details, schedules, themes, and a seamless registration process.

---

## Problem Statement
Traditional event platforms often suffer from static, unengaging, and outdated designs that fail to capture the excitement of modern technology summits. **InnovateX 2026** solves this by providing a highly dynamic, visually striking, and interactive platform. By utilizing glassmorphism, fluid animations, and a premium dark theme, the platform ensures higher user engagement, clearly communicates complex event information, and streamlines the registration process for attendees.

---

## Features of the System

- **Immersive Hero Section:** Engaging landing area with floating animated shapes, pulsing glows, and a clear call-to-action.
- **Scroll-Reveal Animations:** Elements naturally fade and slide into view as the user scrolls, creating a fluid browsing experience without overwhelming performance.
- **Dynamic Event Schedule:** Staggered interactive cards detailing the event timeline, locations, and speakers.
- **Interactive Theme Explorer:** Expandable theme cards (AI, Healthcare, FinTech, Sustainability) with custom hover states, neon glows, and detailed topic breakdowns.
- **Comprehensive Registration System:** A responsive registration form with real-time field validation, focus-state highlights, and an animated success state.
- **Floating Action Button:** A persistent, glowing "Register Now" button that allows users to quickly jump to the registration section from anywhere on the page.
- **Smart Navigation:** A sticky glassmorphism navbar with active-section tracking and smooth-scroll anchor links.
- **Premium Dark UI:** A cohesive design system utilizing deep navy/black backgrounds, cyan/purple gradients, and glassmorphism elements.

---

## Tech Stack Used

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Library:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **UI Components:** Radix UI Primitives (Accordion, etc.)
- **Icons:** Lucide React
- **Animations:** Custom CSS Transitions, Keyframes, and Intersection Observer API

## Setup Instructions

Follow these steps to run the project locally on your machine:

### Prerequisites
Ensure you have **Node.js** (v18 or higher) and **pnpm** installed on your system.

### 1. Clone or Open the Repository
Navigate to the project directory in your terminal:
```bash
cd "d:\dounloads\IIC PROJECT1"
```

### 2. Install Dependencies
Install the required packages using pnpm:
```bash
pnpm install
```

### 3. Run the Development Server
Start the local development server with Turbopack:
```bash
pnpm dev
```

### 4. View the Application
Open your web browser and navigate to:
**[http://localhost:3000](http://localhost:3000)**
